# 給 Gemini 的生成規格：unit22 工坊地圖＋畫畫屋＋4 個小遊戲

主線四關（`rescue.html`）見 `unit22-gemini-prompt.md`。這份是其餘 6 頁：
每頁送給 Gemini 的提示詞＝「共用規範」＋該頁的「頁面規格」＋第一版的角色 SVG 程式碼（`characters.js` 片段）。
組裝與送出由 Claude 用 `agy -p` 處理（唯讀模式，提示詞開頭明令不准用工具）。
2026-11-19 使用者定：地圖自由區、畫畫屋＋接禮物＋翻牌＋裝飾聖誕樹＋堆雪人全做、麋鹿棕鼻子、注音字型、標題不能糊。

## 共用規範

```
【回覆方式】不要使用任何工具：不要建立或寫入檔案、不要執行指令、不要讀取資料夾。
直接把完整程式碼寫在你的文字回覆裡。

這是台灣國小三、四年級資訊課網頁遊戲「聖誕工坊大救援」的其中一頁，單一 HTML 檔。
同一個資料夾裡還有其他頁面，所以風格、角色、字型要和下面規範完全一致。
以「好玩」為第一優先。

【使用情境】老師用單槍投影示範、學生用教室電腦玩。橫向寬螢幕（約 1280×800）是主版面；
手機直立是次要情境，用 @media (orientation: portrait) 另外重排，不可橫向捲動，不要把整體改成直式。

【聖誕（耶誕）風格要貫穿整個畫面】
深藍夜空或暖色室內場景＋飄雪；燈串、聖誕樹、花圈、拐杖糖、薑餅人、聖誕襪、冬青葉與紅果、雪人。
按鈕做成禮物盒或拐杖糖紅白斜紋；面板做成聖誕卡片（雙層邊框＋角落冬青葉）；局部用紅綠格紋底紋與金色亮點。
主色：聖誕紅 #c0392b、深紅 #8e1c14、松樹綠 #1e7a4c、暖金 #e6a817、夜空深藍 #142850、奶油白 #fff8e6。
用語用台灣習慣：「聖誕節」「聖誕老公公」「聖誕快樂」。

【角色】叮叮（小精靈）與雪球（麋鹿）是原創角色，請直接使用下面附的 svgDingDing()、svgSnowball() 程式碼，
不要自己重畫，讓每一頁長得一樣。雪球的鼻子是棕色，絕對不要畫成紅鼻子。
不要使用任何卡通、電影裡的現成角色或聖誕歌曲旋律。

【字型（照抄這段）】
  <link href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@500;700;900&display=swap" rel="stylesheet">
  @font-face { font-family: 'Bpmf Huninn'; src: url('fonts/bpmf-huninn-xmas.woff2') format('woff2'); font-display: swap; }
- 要給學生讀的文字（說明、題目、提示、按鈕）用 font-family: 'Bpmf Huninn', 'Noto Sans TC', sans-serif;
  這是注音字型：每個字右邊會自動出現注音，注音只有字的三分之一大，所以這類文字至少 24px，按鈕至少 24px，
  並且 body 要加 font-synthesis: none（這套字型只有一種粗細，瀏覽器硬加粗會讓注音糊掉）。
- 上方狀態列、計分數字、小標籤等短字用 'Noto Sans TC'（沒有注音），可以小一點但至少 16px。
- 大標題用 'Noto Sans TC' 900，實心奶油白字＋銳利的立體厚度，例如
    color:#fff8e6; text-shadow: 0 2px 0 #c0392b, 0 4px 0 #a02a1f, 0 6px 0 #7a1c13, 0 8px 12px rgba(0,0,0,.35);
  不要用 background-clip:text 漸層透明字，也不要用 filter: drop-shadow 或大範圍模糊陰影（投影上會糊）。

【畫面固定元素】
- 左上角留 120×44px 空白（整合時放「回首頁」按鈕）。
- 右上角放「🗺 回工坊地圖」按鈕（連到 index.html）與音效開關（🔊／🔇）。地圖頁本身不用放回地圖按鈕。

=============== 技術約束，請務必遵守 ===============
1. 單一 HTML，CSS／JS 內嵌，不用框架或建置工具。
2. 不引用外部圖片、音效、影片；插畫用 inline SVG 或 CSS，音效用 Web Audio API 即時合成（原創音型）。
   外部資源只允許上面那行 Google Fonts；字型檔 fonts/bpmf-huninn-xmas.woff2 是同資料夾的檔案。
3. emoji 只用 2015 年以前的：🎄 🎁 ⭐ 🔔 ⛄ ❄ 🎅 ✉ 🏠 🌙 🔊 🔇 🗺 🎨 ✏ 🍪 不要用 2019 年後的新 emoji。
4. localStorage key 一律 edtech-unit22- 前綴（各頁指定的 key 見頁面規格），讀寫都包 try/catch。
5. 支援 @media (prefers-reduced-motion: reduce)：關掉動畫與飄雪，遊戲仍可玩。
6. 可點、可拖的元素有 cursor: pointer（拖曳用 grab）與 hover／按下回饋；拖曳用 pointer events，滑鼠與觸控都能用。
7. 彈出視窗關閉時加 visibility:hidden（或 inert），不要只用 opacity:0。
8. SVG points 屬性只用數字，不用百分比。
9. 若用固定 px 畫布＋JS scale 縮放，盒子要加 flex-shrink: 0。
10. console 不能有任何錯誤。
11. 中文註解說明各區塊；面向使用者的文字集中成常數方便老師修改。
12. 不做姓名、學校、班級欄位，不做證書。

=============== 交件格式 ===============
只回覆：(1) 一個完整的 ```html 程式碼區塊（<!DOCTYPE html> 到 </html>，不可省略）
(2) 程式碼後附自檢表，逐條列出 12 條技術約束是否做到。
```

## 頁面規格

### index.html — 工坊地圖

```
【這一頁】聖誕工坊地圖（遊戲首頁）。
開場：標題「聖誕工坊大救援」＋叮叮與雪球揮手＋一句「今天想去工坊的哪裡呢？」。
主畫面是一張俯視的聖誕工坊小鎮地圖（雪地、小路、路燈、燈串），上面有 6 個可以點的建築，各有名牌：
  1. 送禮電腦室（大建築、最顯眼，標示「主線冒險」）→ rescue.html：四關闖關救援
  2. 畫畫屋（屋頂有調色盤）→ draw.html：聖誕卡片畫畫屋
  3. 雪橇跑道 → catch.html：雪橇接禮物
  4. 記憶小木屋 → memory.html：聖誕翻牌配對
  5. 聖誕樹廣場 → tree.html：裝飾聖誕樹
  6. 雪人公園 → snowman.html：堆雪人
滑鼠移上建築會亮起、微微彈跳並顯示一句介紹；點下去前往該頁。
從 localStorage 讀以下 key 顯示徽章（讀不到就不顯示）：
  edtech-unit22-score（主線最高星數 0～12，顯示「⭐ x/12」）
  edtech-unit22-catch-best（接禮物最高分）、edtech-unit22-memory-best（翻牌最少步數）
  畫畫屋、聖誕樹、雪人沒有分數，有玩過（edtech-unit22-draw-done、-tree-done、-snowman-done 為 '1'）就在名牌旁亮一顆小星星。
這一頁本身不寫任何 localStorage。
手機直立：地圖改成上下排列的 6 張大卡片，每張有建築小圖與名稱。
```

### draw.html — 聖誕卡片畫畫屋

```
【這一頁】聖誕卡片畫畫屋：自由畫一張聖誕卡片。
- 中間是卡片畫布（canvas，橫式約 900×560，手機直立改直式），先選卡片底圖：
  空白奶油色、雪夜窗景、聖誕樹輪廓（淡淡的線稿讓學生塗色）、雪人輪廓。底圖用程式畫在 canvas 上，不用外部圖。
- 工具列：畫筆（3 種粗細）、12 色聖誕色盤＋彩虹筆（顏色會一直變）、油漆桶填色（輪廓線稿可以一鍵塗滿區塊）、
  橡皮擦、貼紙（點一下蓋上：星星、鈴鐺、禮物、聖誕襪、雪花、拐杖糖、薑餅人、叮叮、雪球，貼紙用 SVG 畫成圖再畫進 canvas，
  可以選大小）、文字（輸入「聖誕快樂」等字蓋上去，用注音字型）、上一步（至少 20 步）、全部清除（要先確認）。
- 「存成圖片」按鈕：canvas.toDataURL 後用 <a download="聖誕卡片.png"> 下載。
- 畫畫時有輕輕的沙沙聲（可關）；蓋貼紙有叮一聲。
- 第一次存圖或畫超過 30 筆後，localStorage 設 edtech-unit22-draw-done = '1'。
- 工具按鈕要大（至少 56px），圖示＋注音文字，三四年級一看就懂。
```

### catch.html — 雪橇接禮物

```
【這一頁】雪橇接禮物：雪球拉著雪橇在畫面下方左右移動，接住從天上掉下來的禮物。
- 操作：鍵盤 ← → 鍵，或滑鼠／手指左右拖曳，兩種都要支援；開始畫面清楚說明。
- 掉落物：一般禮物 +1、金色大禮物 +3、星星（3 秒內接到的分數加倍）、煤炭（接到扣 1 顆心，共 3 顆心）。
- 難度：60 秒一局，越後面掉得越快、越多；不要難到挫折，前 15 秒不出現煤炭。
- 結束畫面：分數、最高紀錄、依分數給 1～3 顆星（門檻留緩衝）、「再玩一次」。
- 最高分存 edtech-unit22-catch-best（數字，只在破紀錄時更新）。
- 背景：夜空、月亮、遠方小鎮燈火，雪橇移動時留下金色亮粉軌跡。接到有閃光與分數飄字。
```

### memory.html — 聖誕翻牌配對

```
【這一頁】聖誕翻牌配對（記憶遊戲）。
- 3 個難度：簡單 3×4（6 對）、普通 4×4（8 對）、挑戰 4×5（10 對）。
- 牌面圖案用 SVG 畫：聖誕樹、雪人、禮物、鈴鐺、星星、聖誕襪、拐杖糖、薑餅人、花圈、叮叮、雪球（棕鼻子），每張下方有注音字名稱。
- 牌背是紅綠格紋＋金色雪花。翻牌有 3D 翻轉動畫；配對成功兩張牌發光並跳一下；失敗 1 秒後蓋回。
- 顯示步數與計時；完成時顯示「你用了 N 步」並給 1～3 顆星（門檻留緩衝）、「再玩一次」。
- 各難度最少步數存在 edtech-unit22-memory-best（JSON：{ easy, normal, hard }，只在破紀錄時更新）。
- 鍵盤也能玩：Tab 移動到牌、Enter／空白鍵翻牌。
```

### tree.html — 裝飾聖誕樹

```
【這一頁】裝飾聖誕樹：把裝飾品拖到一棵大聖誕樹上，自由布置，沒有對錯。
- 左邊（直立版在下方）是裝飾品盒：彩球（6 色）、星星、鈴鐺、拐杖糖、薑餅人、蝴蝶結、小禮物、燈串（拖上去自動沿樹畫一圈）。
- 樹頂可以放一顆大星星，放上去整棵樹的燈亮起來並播放叮噹聲。
- 放上去的裝飾可以再拖動位置、拖回盒子刪除；有「全部清除」（要先確認）與「關燈／開燈」（關燈時只有燈串和星星會發光，很漂亮）。
- 樹下可以拖放禮物盒堆起來。
- 「拍照」按鈕：把目前畫面畫成圖片下載（可以用 SVG 序列化後畫進 canvas 再 toDataURL）。
- 放滿 8 個以上裝飾後，localStorage 設 edtech-unit22-tree-done = '1'，並讓叮叮跳出來說「好漂亮的聖誕樹！」。
```

### snowman.html — 堆雪人

```
【這一頁】堆雪人：照「任務卡」的提示，選對部位組出指定的雪人；也有自由模式。
- 任務模式：共 6 張任務卡，例如「戴紅色帽子、圍綠色圍巾、紅蘿蔔鼻子、三顆黑鈕扣」。
  部位分類：帽子（毛帽、高帽、聖誕帽，各有顏色）、圍巾（紅、綠、格紋）、鼻子（紅蘿蔔、鈕扣、櫻桃）、
  眼睛（煤炭、鈕扣、星星）、手（樹枝、手套）、鈕扣（1～3 顆）。點選部位就套到雪人上，可以換。
  按「完成」檢查：全對就過關（雪人跳舞＋彩帶）；有錯就用叮叮的話提示哪個部位不一樣（例如「圍巾的顏色再看看任務卡喔」），可以改。
  任務卡文字要用注音字型，讓學生練習「看文字指示操作」。
- 自由模式：沒有任務卡，隨意搭配，可以「拍照」下載圖片。
- 完成 3 張任務卡後，localStorage 設 edtech-unit22-snowman-done = '1'。
- 背景：白天的雪地公園、松樹、木頭長椅、遠方的工坊。
```

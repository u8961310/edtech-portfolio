# 打字島三階改版：設計稿需求（三版共用）

給台灣國小學生（1–6 年級）的打字遊戲。打字島 8 關要重新設計，**這份設計稿要定出 8 關共用的視覺語言與版面**。
三個設計 skill 各出一版，老師看過選一版（或混搭）才開始開發。

## 使用情境
- 學校電腦教室，一人一台筆電，可視區約 **1366×657**（橫向寬螢幕是唯一主版面）
- **每個畫面一屏放得下，不能上下捲動**
- 學生年紀小：字要大、按鈕要大、資訊不能太擠；1–3 年級看得懂

## 必須用真素材（不要模擬）
- 注音字型：`fonts/bpmf-huninn-typing.woff2`（注音粉圓 Bpmf Huninn 子集，字本身就畫好右側注音，字寬約 1.35em）。
  `@font-face { font-family:'Bpmf Huninn'; src:url('fonts/bpmf-huninn-typing.woff2') format('woff2'); }`
  **不要用 `<ruby>` 或自己排注音**，也不要用資料夾裡另一個 `bpmf-huninn-mockup.woff2`（那是舊單元的）
- 選文：`<script src="typing-data/passages.js"></script>` 會定義 `window.PASSAGES`（陣列）。每篇欄位：
  `id, grade('t1'|'t2'|'t3'), domain('唐詩'|'宋詞'|'三字經'), title, author, gloss(白話一句), text, zhuyin(逐字注音陣列，標點為 ""), ivs({索引: n})`
- 破音字顯示：`ivs[i]` 有值且 n>1 時，在該字後面接 `String.fromCodePoint(0xE01E0 + n - 1)`，字型就會畫出指定讀音。比對學生輸入用原字。
- 範例篇目：初階用 `tang-1-01`〈靜夜思〉；進階用 `tang-2-01`〈早發白帝城〉（「朝」「還」「重」有指定讀音，可檢查 IVS 有沒有畫對）
- 介面文字用 Noto Sans TC（Google Fonts）；數字字體可自選但要支援 Windows

## 要畫的 5 個畫面（同一個 HTML 檔，用分頁按鈕或並排切換，每個畫面都是 1366×657 一屏）
1. **設定面板（開局前）**
   - 階級：初階（1–3 年級）／進階（4–5 年級）／高階（6 年級）
   - 注音：初階、進階固定開（顯示鎖住的說明）；高階才出現開關
   - 時間：10／15／20 分鐘
   - 中打文章：唐詩／宋詞／三字經／隨機
   - 「開始」大按鈕；旁邊一張**本局目標卡**（Gagné 告知目標），例：「正確率 90% 以上、打完 3 首詩」
2. **射擊類遊戲中**（例：太空主題，打對字就發射子彈擊落目標，目標掉到底線扣血）
   - 上方：回合進度（例：第 2／5 回合）、剩餘時間（例：08:12）、血量、連擊數、正確率
   - 主畫面：目標物帶著要打的字往下掉
   - 下方：目前這首詩一行，**目前要打的字用框框起來**，已打對的字變淡
   - 提示階梯（分層回饋，三層都要畫出至少一層的樣子）：① 字框紅閃 ② 顯示這個字的注音按鍵（鍵帽，例：ㄔ ㄨ ㄤ ˊ → [T][J][;][6]，大千鍵盤） ③ 鍵盤圖標出位置
3. **怪獸對打類遊戲中**（例：小勇者對怪獸，打對字角色出招扣怪獸血，打錯或太慢怪獸反擊）
   - 雙方角色、血條、連擊／傷害加成、同樣的詩句區＋目前字框、提示列
4. **回合／結算回顧**（Gagné 回顧）
   - 每分鐘字數、正確率、跟上次比
   - 最常打錯的 5 個字（字＋注音鍵帽）
   - 這首詩的白話一句（gloss）
   - 「再玩一次」「換文章」按鈕；初階要有鼓勵語

5. **闖關獎狀（老師 11-20 加）**：一局所有回合打完、達到本局目標後頒發，也要 1366×657 一屏
   - 像真的獎狀：標題「獎狀」、學生名字（範例「王小明」，開發時第一次闖關會問名字、存在瀏覽器）
   - 內容句：例「在打字島〈唐詩・初階〉闖關成功，正確率 96%、每分鐘 32 字，特頒此狀以資鼓勵」
   - 稱號依星等（1–3 顆星，例：打字小學徒／小高手／小達人）、日期（民國年，例：中華民國 115 年 11 月 20 日）、打字島印章（CSS／SVG 畫）
   - 按鈕：「列印獎狀」「回到打字島」；列印時只印獎狀本體（`@media print`）
   - 風格跟你這版一致（可愛風）

## 配色要適合國小 6–12 歲（老師 11-20 加）
- 主色用明亮、飽和度中高的清楚色（如晴天藍、草綠、陽光黃、番茄紅、橘），不要整片灰濛濛的粉彩；粉彩只當大面積底色或卡片底
- 底色淺而乾淨、字一律深色；資訊文字對比 ≥ 4.5:1，打字區的字與注音 ≥ 7:1（小朋友要一眼看清注音）
- 一個畫面主色 3–4 個以內，各有固定意思：目前字／重點一個色、正確一個色、錯誤一個色、按鈕一個色，8 關共用不換
- 對、錯不能只靠紅綠分辨（約 8% 男生紅綠色弱）：同時用圖示（✓ ✗）、形狀或文字
- 不用螢光／霓虹色、不用大面積高彩度閃爍；不用暗色底
- 低年級（初階）可以更鮮豔一點，高階可以稍微沉穩，但同一套色票
- **眼睛保健**（一局 10–20 分鐘盯螢幕）：
  - 大面積底色不用純白 #FFFFFF，用柔和米白／淺暖色（亮度約 94–97%）減少眩光；字用深藍灰或深咖啡，不用純黑 #000
  - 高彩度色只用在小面積（目前字框、按鈕、角色），不鋪滿背景；遊戲場景底用柔和的天空藍、草綠等低刺激色
  - 閃爍：每秒不超過 3 次（WCAG 2.3.1），紅閃提示用柔和脈動 1–2 次就停，不連續閃；大爆炸、滿版閃光不做
  - 字夠大：打字區國字 ≥ 40px（含注音），介面文字 ≥ 16px；行距寬鬆
  - 回合之間的「休息一下」卡要畫：提醒「看看遠方 20 秒」「眨眨眼」，倒數 20 秒可略過（20-20-20 護眼原則）

## 鍵盤示意圖要跟真正的鍵盤一樣（老師 11-20 加）
- 完整主鍵區 5 排，照實體筆電鍵盤：
  - 數字排：` 1 2 3 4 5 6 7 8 9 0 - = Backspace（Backspace 約 2 格寬）
  - 上排：Tab（1.5 格）Q W E R T Y U I O P [ ] \（\ 1.5 格）
  - 中排：Caps Lock（1.75 格）A S D F G H J K L ; ' Enter（2.25 格）
  - 下排：Shift（2.25 格）Z X C V B N M , . / Shift（2.75 格）
  - 空白鍵排：Ctrl、Win、Alt、長空白鍵（約 6 格）、Alt、Ctrl
- 每排照真鍵盤錯位（上排比數字排右移半格、中排再右移、下排再右移），F、J 鍵畫定位凸點
- 每個鍵左上英文字母、右下注音符號（大千排列，不能錯）：
  - 1ㄅ 2ㄉ 3ˇ 4ˋ 5ㄓ 6ˊ 7˙ 8ㄚ 9ㄞ 0ㄢ -ㄦ
  - Qㄆ Wㄊ Eㄍ Rㄐ Tㄔ Yㄗ Uㄧ Iㄛ Oㄟ Pㄣ
  - Aㄇ Sㄋ Dㄎ Fㄑ Gㄕ Hㄘ Jㄨ Kㄜ Lㄠ ;ㄤ
  - Zㄈ Xㄌ Cㄏ Vㄒ Bㄖ Nㄙ Mㄩ ,ㄝ .ㄡ /ㄥ
  - 空白鍵＝一聲
- 要按的鍵發亮並標順序（①②③），鍵帽提示（第 2 層）也用同一套對照，程式產生、不要手打
- 鍵盤可以縮小放，但比例、錯位、按鍵數不能省；可選用顏色標示左右手手指分區

## 底線（三版都要守）
- 文字對比 ≥ 4.5:1（大標題 ≥ 3:1）
- 單一 HTML 檔，不用建置工具；只可從 Google Fonts 載字型、不要其他外部資源
- `prefers-reduced-motion` 時關掉大動畫
- 角色、目標物用 inline SVG 或 CSS 畫（不要外部圖片）；emoji 只用 Windows 10 有的
- **風格一律「可愛風」（老師 11-20 指定）**：明亮、溫暖、Q 版角色，給 1–6 年級；不要深色夜空／暗底。三版在可愛範圍內各走不同方向（見各自的指示），仍要有明顯差異

## 交付
- 檔案：`docs/plans/mockups/typing-island-<skill名>.html`（跟 `fonts/`、`typing-data/` 同層）
- 自己用瀏覽器實際開（`python -m http.server` 在 mockups 資料夾，不能用 file://），1366×657 四個畫面各截圖目視：不捲動、注音字型有載到、IVS 讀音有畫對、沒有重疊
- 回報：檔名、風格一句話、焦點元素、skill 原本建議但你改掉的地方（例如推薦字體不支援中文）、目視檢查結果

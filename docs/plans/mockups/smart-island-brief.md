# 小常識島改版：設計稿需求（三版共用）

給台灣國小 1–4 年級的資訊常識遊戲。小常識島 6 關要換成同一套外殼與視覺語言，主軸是 **「數位寵物養成」**：孩子領養一隻寵物寶寶，每過一關拿點心餵牠，集滿會長大，還能解鎖服裝。
**這份設計稿要定出 6 關共用的視覺語言、寵物長相與版面。** 三個設計 skill 各出一版，老師選一版（或混搭）才開始開發。規劃頁：`docs/plans/2026-11-21-smart-island-plan.html`。

## 使用情境
- 學校電腦教室，一人一台筆電，可視區約 **1366×657**（橫向寬螢幕是唯一主版面）；也要能用平板觸控（按鈕 ≥ 44px）
- **每個畫面一屏放得下，不能上下捲動**
- 教室電腦很多班共用：領養時要輸入**座號＋名字**，一台電腦可以有好幾隻寵物
- 1–2 年級識字少：字大、按鈕大、圖示＋短句；3–4 年級可以多一點文字
- 風格：**有趣、可愛**，寵物是情感核心（孩子要想回來看牠），但題目本身要清楚好讀，裝飾不能干擾作答

## 寵物（4 隻原創，名字暫定）
**必須是原創角色**，不能像任何現有遊戲或卡通角色（不要像寶可夢、電子雞、三麗鷗、拓麻歌子等）。造型帶一點「數位」元素，但先可愛再數位：
| 暫定名 | 概念 |
|---|---|
| 雲朵兔 | 白白軟軟像雲，耳朵尖端有像 Wi-Fi 訊號的弧線 |
| 鍵盤龜 | 背殼是一格一格的鍵盤按鍵 |
| 螢幕貓 | 臉是一個圓角小螢幕，表情顯示在螢幕上 |
| 燈泡雞 | 頭頂一顆小燈泡，想到點子會亮 |
- 每隻要有 **3 個成長階段**：寶寶 → 小朋友 → 大朋友（同一隻，看得出長大）
- 至少 3 種表情：開心、普通、驚訝／擔心
- 服裝範例：圍巾、帽子、眼鏡（疊在寵物身上）
- 用 inline SVG 畫（可以重複使用 `<symbol>`／`<use>`），**不要外部圖片、不要用 emoji 當寵物或主要圖案**（Windows 上 emoji 會變醜）；🏠 這種小圖示可以

## 必須用真素材（不要模擬）
- 注音字型：`fonts/bpmf-huninn-smart.woff2`（注音粉圓 Bpmf Huninn 子集，字本身就畫好右側注音，字寬約 1.35em）
  `@font-face { font-family:'Bpmf Huninn'; src:url('fonts/bpmf-huninn-smart.woff2') format('woff2'); }`
  **不要用 `<ruby>` 或自己排注音。** 注音字型只用在下面標【注音】的句子（1–2 年級要讀的），其他介面文字用 Noto Sans TC（Google Fonts）。字型檔會在你寫完後由老師那邊產生，你照路徑寫就好。
- 【注音】句子**一字不改照抄**（破音字已經挑掉，改字會出現錯的讀音）：
  - 領養：「挑選你的寵物寶寶，幫牠取名吧！」
  - 寵物的新電腦 玩法：「寵物買了新電腦！請你幫牠找出滑鼠。」
  - 題目：「滑鼠在哪裡？」
  - 答對：「答對了！寵物好開心。」
  - 答錯（寬鬆，還是讓孩子繼續）：「別擔心，再想想看！」
  - 結算：「寵物吃到點心，好開心！」「再過兩關，就能拿到新眼鏡！」
- 其他畫面文字照下面寫的用，不要換成英文或 lorem ipsum

## 6 關（設計時心裡要有這張表，畫面只要畫其中幾關）
| 關卡 | 年段 | 一句話 | 對應 |
|---|---|---|---|
| 寵物的新電腦 | 1–2 | 認識螢幕、鍵盤、滑鼠、主機、耳機等設備 | 資E1 |
| 寵物作息表 | 1–2 | 幫寵物排一天：看螢幕多久要休息、坐姿、護眼 | 資E11 |
| 寵物收到怪訊息 | 3–4 | 陌生人私訊、要密碼、中獎連結：選擇怎麼回應 | 資E12、資E7 |
| 寵物的 AI 作業 | 3–4 | AI 幫忙寫作業可以嗎？判斷哪些用法 OK | 資E12、資E2 |
| 寵物房間大整理 | 1–4 | 把檔案拖進正確資料夾（舊關「桌面整理大師」重做） | 資E8 |
| 寵物警察訓練 | 3–4 | 判斷網路行為安不安全（舊關「網路小警察」重做） | 資E12 |

## 要畫的 5 個畫面（同一個 HTML 檔，上方分頁按鈕切換，每個畫面都是 1366×657 一屏）
1. **領養畫面**
   - 左上「🏠 首頁」（一定要有，回 `../../index.html`）
   - 句子【注音】「挑選你的寵物寶寶，幫牠取名吧！」
   - 4 隻寵物寶寶並排（可以是蛋剛孵出來的感覺），選中的有明顯外框
   - 輸入欄：「座號」（數字）、「你的名字」、「寵物名字」；大按鈕「領養」
   - 旁邊小字：「這台電腦已經住了 3 隻寵物」＋ 3 個小頭像可以點（共用電腦切換用）
2. **寵物小屋（小常識島的大廳）**
   - 寵物在小屋裡（小朋友階段、戴著圍巾），名字「小雲」、主人「12 號 王小明」
   - 成長條：「點心 5／8，再 3 個就長大」
   - 6 關卡片：關卡名、年段標籤（1–2 年級／3–4 年級／1–4 年級）、已過的顯示星星（例：寵物的新電腦 ★★★、寵物作息表 ★★、寵物房間大整理 ★★★，其他還沒玩）
   - 衣櫃區：圍巾（已解鎖、穿著中）、帽子（已解鎖）、眼鏡（鎖住，「再過 2 關」）
   - 右上「🔄 換寵物」
3. **遊戲中：寵物的新電腦**（1–2 年級）
   - 句子【注音】「寵物買了新電腦！請你幫牠找出滑鼠。」、題目【注音】「滑鼠在哪裡？」
   - 一張書桌場景：螢幕、鍵盤、滑鼠、主機、耳機（SVG 畫，可以點）
   - 寵物在旁邊看（期待的表情）；進度「第 2 題／共 5 題」
   - **另畫兩個小狀態**（畫面角落或第二張卡）：答對 → 寵物開心＋【注音】「答對了！寵物好開心。」；答錯 → 寵物擔心但溫和＋【注音】「別擔心，再想想看！」
   - 對錯不能只靠紅綠：同時用 ✓ ✗、圖示或文字
4. **遊戲中：寵物收到怪訊息**（3–4 年級，一般字型即可）
   - 一個像聊天 App 的視窗：陌生帳號「抽獎小幫手」傳來「恭喜你中獎了！把你的帳號密碼傳給我，就送你 1000 點遊戲幣」
   - 寵物在旁邊冒問號
   - 3 個選項卡：「傳密碼給他，拿遊戲幣」「不回覆，告訴爸媽或老師」「先問他是誰再說」
   - 進度「第 3 題／共 6 題」；右下一個「💡 提示」按鈕
   - 小區塊給老師看：「這關練什麼：辨識網路詐騙、保護個資｜資E12、資E7」（小字可以，但對比要夠）
5. **結算：吃點心**
   - 寵物在吃點心（開心表情），旁邊星星 ★★★、【注音】「寵物吃到點心，好開心！」
   - 成長條動起來的樣子（5／8 → 6／8）、【注音】「再過兩關，就能拿到新眼鏡！」
   - 這關的回顧：答對 6／6、一句學到什麼（例：「不認識的人要密碼，一定不給」）
   - 按鈕：「交成績給老師」「再玩一次」「回寵物小屋」「🏠 首頁」

## 配色適合國小 6–10 歲
- 主色明亮、飽和度中高；粉彩當大面積底或卡片底；不用螢光／霓虹、不用暗色底
- 一個畫面固定意思色 3–4 個（重點／按鈕／正確／錯誤），6 關共用不換
- 對錯不能只靠紅綠；護眼：大面積底不用純白 #FFFFFF（亮度約 94–97% 的柔和色）；字用深色不用純黑；不連續閃爍（每秒 ≤ 3 次）

## 跟現有網站的關係
- 打字島「繪本剪紙」風（米色紙、白卡紙、牛皮紙邊、Q 版小狐狸）；畫畫島「貼紙畫冊」風（湖水綠 #E4F1F0 底、深藍字 #1F2A4D、藍 #2160C4、黃 #FFB627，白卡片加貼紙感外框）。
- 小常識島要**有自己的個性**，但放在同一個學習樂園網站不能突兀。可以參考，不用照抄。

## 底線（三版都要守）
- 文字對比 ≥ 4.5:1（大標題 ≥ 3:1）
- 1366×657 每個畫面不捲動
- 單一 HTML 檔、不連外部圖片；字型只用 Google Fonts（Noto Sans TC 等）＋上面的注音字型
- 檔名照指定，放在這個資料夾

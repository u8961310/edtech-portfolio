# 畫畫島改版：設計稿需求（三版共用）

給台灣國小 1–4 年級的畫畫遊戲。畫畫島 6 關要換成同一套外殼與視覺語言，**這份設計稿要定出 6 關共用的視覺語言與版面**。
三個設計 skill 各出一版，老師看過選一版（或混搭）才開始開發。規劃頁：`docs/plans/2026-11-21-art-island-plan.html`。

## 使用情境
- 學校電腦教室，一人一台筆電，可視區約 **1366×657**（橫向寬螢幕是唯一主版面）；也要能用平板觸控（按鈕、工具 ≥ 44px）
- **每個畫面一屏放得下，不能上下捲動**
- 1–2 年級識字少：字要大、按鈕要大、用圖示＋短句；3–4 年級可以多一點資訊
- 有趣優先：畫面要讓小朋友一看就想玩，但這是「畫畫」的地方，**畫布永遠是主角**，裝飾不能搶畫布

## 必須用真素材（不要模擬）
- 注音字型：`fonts/bpmf-huninn-art.woff2`（注音粉圓 Bpmf Huninn 子集，字本身就畫好右側注音，字寬約 1.35em）
  `@font-face { font-family:'Bpmf Huninn'; src:url('fonts/bpmf-huninn-art.woff2') format('woff2'); }`
  **不要用 `<ruby>` 或自己排注音。** 注音字型只用在下面標【注音】的句子（1–2 年級要讀的），其他介面文字用 Noto Sans TC（Google Fonts）。字型檔會在你寫完後由老師那邊產生，你照路徑寫就好。
- 【注音】句子一字不改照抄（破音字已經挑掉，改字會出現錯的讀音）：
  - 調色魔法鍋 玩法：「把紅、黃、藍顏料拖進大鍋，煮出客人點的顏色！」
  - 客人台詞：「我要橘色的南瓜！」
  - 煮錯時：「哎呀，煮出泥巴色了！倒掉再試一次。」
  - 線條小火車 玩法：「按住滑鼠，跟虛線畫一條鐵軌。」
- 其他畫面文字也照下面寫的用，不要換成英文或 lorem ipsum
- 圖案（南瓜、蝴蝶、房子、角色）用 inline SVG 或 CSS 畫，不要外部圖片；**不要用 emoji 當主要圖案**（Windows 上 emoji 會變醜），🏠 這種小圖示可以

## 6 關（設計時心裡要有這張表，畫面只要畫其中幾關）
| 關卡 | 年段 | 一句話 |
|---|---|---|
| 調色魔法鍋 | 1–2 | 拖紅黃藍顏料進鍋子混色，幫客人的圖上色；煮錯變泥巴色、跳出泥巴怪 |
| 線條小火車 | 1–2 | 沿虛線畫鐵軌（直線、波浪、鋸齒、螺旋），火車照自己畫的線開 |
| 魔法畫畫屋 | 1–2 | 自由畫畫＋主題卡，畫完按魔法會動 |
| 對稱魔鏡工坊 | 3–4 | 畫左半邊，魔鏡同時畫右半邊；模式：左右、上下、萬花筒、雪花 |
| 小畫家任務局 | 3–4 | 照目標圖用繪圖工具畫，算步數、有標準桿 |
| 像素小畫家 | 1–4 | 低年級照號碼填色、中年級照座標畫 |

## 要畫的 5 個畫面（同一個 HTML 檔，用上方分頁按鈕切換，每個畫面都是 1366×657 一屏）
1. **開始畫面**（以「調色魔法鍋」為例，1–2 年級）
   - 左上「🏠 首頁」（一定要有，回 `../../index.html`）、右上「🖼 我的畫廊」
   - 遊戲名「調色魔法鍋」、玩法一句【注音】、一個大大的「開始」按鈕
   - 一個小區塊給老師看：「這關練什麼：三原色混色、深淺變化｜生活課程 2-I-1」（小字可以，但對比要夠）
   - 關卡選擇：第 1 關 橘色南瓜（已過 ★★★）、第 2 關 綠色青蛙（已過 ★★）、第 3 關 紫色葡萄（還沒玩）、第 4 關 淺藍天空（鎖住）
2. **遊戲中：調色魔法鍋**（1–2 年級）
   - 客人（森林小動物）＋對話框台詞【注音】「我要橘色的南瓜！」
   - 5 瓶顏料：紅、黃、藍、白、黑（大、好拖）；中間一口大鍋，鍋裡現在是「紅＋黃」混出的橘色，冒泡泡
   - 旁邊一張南瓜線稿等著上色；按鈕「倒到圖上」「倒掉重來」
   - 角落顯示鍋裡加了什麼（紅 1、黃 1）
   - **另畫一個小狀態**（可以同畫面角落或第二張卡）：煮錯變泥巴色＋泥巴怪做鬼臉＋句子【注音】「哎呀，煮出泥巴色了！倒掉再試一次。」
   - 混色結果要像美術課顏料：紅＋黃＝橘、黃＋藍＝綠、紅＋藍＝紫
3. **遊戲中：對稱魔鏡工坊**（3–4 年級）
   - 任務卡：「訂單 3／5：修好蝴蝶的右邊翅膀」
   - 大畫布在中間，中央一條鏡子線；左邊已畫一半的蝴蝶翅膀，右邊鏡射出一模一樣的（範例圖）
   - 工具列：筆刷 3 種粗細、12 色色盤、橡皮擦、復原、清除；模式切換：左右對稱／上下對稱／萬花筒（4 份）／雪花（6 份）
   - 「完成」按鈕
4. **遊戲中：小畫家任務局**（3–4 年級）
   - 左邊「目標圖」（簡單的房子：矩形屋身、三角屋頂、4 扇一樣的窗、門），右邊「我的畫布」（已畫好屋身和屋頂、1 扇窗）
   - 工具列（要像真的繪圖軟體、圖示＋字）：直線、矩形、橢圓、填色桶、橡皮擦、選取、複製、貼上、復原
   - 步數計：「已用 7 步｜標準桿 9 步」、提示一句「4 扇窗都一樣，有沒有更快的方法？」
5. **完成畫面＋畫廊**
   - 剛完成的作品大圖（例：塗好的橘色南瓜）、星星 ★★★、一句稱讚
   - 按鈕：「下載圖片」「列印」「交成績給老師」「再玩一次」「🏠 首頁」
   - 下方或側邊：畫廊縮圖一排（5–6 張不同關卡作品）

## 配色適合國小 6–10 歲
- 主色明亮、飽和度中高的清楚色；粉彩只當大面積底色或卡片底；不用螢光／霓虹、不用暗色底
- 一個畫面固定意思色 3–4 個（例：重點／按鈕／正確／錯誤），6 關共用不換；**顏料色本身不算介面色**（調色鍋的紅黃藍是畫畫內容）
- 對錯不能只靠紅綠：同時用 ✓ ✗、圖示或文字
- 護眼：大面積底不用純白 #FFFFFF（亮度約 94–97% 的柔和色）；字用深色不用純黑；不連續閃爍（每秒 ≤ 3 次）
- **畫布本身要白（或近白）**，讓顏色看得準；畫布外的介面才用柔和底色

## 跟現有網站的關係
- 打字島用「繪本剪紙」風（`.interface-design/system.md`：米色紙桌面、白卡紙、牛皮紙邊、Q 版小狐狸）。畫畫島要**有自己的個性**，但放在同一個學習樂園網站裡不能突兀。可以參考，不用照抄。

## 底線（三版都要守）
- 文字對比 ≥ 4.5:1（大標題 ≥ 3:1）
- 1366×657 每個畫面不捲動
- 單一 HTML 檔、不連外部圖片；字型只用 Google Fonts（Noto Sans TC 等，要支援中文或只用在數字）＋上面的注音字型
- 檔名照指定，放在這個資料夾

# 首頁改版 B 方案「年級入口＋嚮導角色」：設計稿需求（三版共用）

學習樂園島首頁（`index.html`）是一張插畫版 3D 島嶼地圖，8 座島、35 個入口，全攤開不分年級。
這次要加上「年級入口＋嚮導寵物＋建議路線」，讓一年級第一次進來也知道從哪裡玩。三個設計 skill 各出一版，老師選一版才開發。
規劃頁：`docs/plans/2026-11-21-home-b-plan.html`。

## 真素材（都在 `home-data/`，一定要用，不要自己畫假地圖）
- `home-map.png`：現在首頁的地圖（1366×657，已經是首頁的預設鏡頭，沒有 UI）。設計稿用它當地圖底圖，路線、變淡、泡泡都疊在上面
- `home-now.png`：現在首頁含 UI 的樣子（左上「🏝️ 我的學習樂園島」、右上「⭐ 2/35」「📥 收成績」「👨‍🏫」、下方「🌏 全景｜📋 清單」）
- `units.json`：35 個入口在 1366×657 畫面上的中心座標 `pos`、所屬島 `island`、短名 `short`、年級標籤 `grade`、年級範圍 `range`（例 [1,2]、[3,4]、[1,6]）；`islands` 有 8 座島名牌的座標
  - 依 `range` 算：1–2 年級 25 關、3–4 年級 20 關、5–6 年級 7 關
- `smart-pet.js`：4 隻寵物（小常識島的雲朵兔、鍵盤龜、螢幕貓、燈泡雞）的繪圖程式，用 `<script src="home-data/smart-pet.js">` 載入，
  `SmartPet.svg('bunny', 1, 'happy')` 會回傳 SVG 字串（type：bunny／turtle／cat／chick；stage 0 寶寶／1 小朋友／2 大朋友；mood：happy／normal／worried／surprised）。
  嚮導一律用這 4 隻，不要另外畫角色
- 注音字型：`fonts/bpmf-huninn-home.woff2`（注音粉圓子集，字本身就畫好注音），`@font-face { font-family:'Bpmf Huninn'; src:url('fonts/bpmf-huninn-home.woff2') format('woff2'); }`。
  只用在下面標【注音】的句子，**一字不改照抄**；不要用 `<ruby>`。字型檔在你寫完後由老師那邊產生，照路徑寫就好
  - 【注音】歡迎卡：「嗨！你幾年級？」
  - 【注音】選嚮導：「選一隻寵物陪你逛樂園！」
  - 【注音】嚮導泡泡：「下一站：拔蔬菜！」
  - 【注音】路線提示：「照虛線一站一站玩！」

## 使用情境
- 學校電腦教室 1366×657 為主（也要想到平板、直向手機，但設計稿畫 1366×657 即可），一屏不捲動
- **教室電腦很多班共用**：第 3 節三年級、第 4 節一年級。年級只記到當天結束，隔天重問；換班時學生按右上角年級膠囊就能改
- 老師上課投影：網址加 `?grade=all` 或 `?grade=12` 直接略過歡迎卡
- 1–2 年級識字少：大按鈕、圖示＋短句、注音

## 要畫的 4 個畫面（同一個 HTML 檔，上方分頁切換，每個畫面 1366×657）
1. **歡迎卡（第一次打開）**：地圖在後面淡淡的，前面一張卡：嚮導寵物＋【注音】「嗨！你幾年級？」＋4 個大按鈕：1–2 年級、3–4 年級、5–6 年級、我是老師／全部看看
2. **選嚮導**（選完年級後；也可以跟第 1 步合在同一張卡，你決定）：4 隻寵物寶寶＋【注音】「選一隻寵物陪你逛樂園！」；如果這台電腦在小常識島已經領養過寵物，可以直接用那隻（畫一個「用我的小雲」的選項）
3. **地圖＋建議路線（以 1–2 年級為例）**：
   - 適合 1–2 年級的島與入口正常顯示，不適合的（例如只有 5–6 年級的「魔法字彈」）**輕度變淡但還點得到**
   - 建議路線：**不要把 25 站畫成一條線**（會亂成一團），請你提出讀得懂的做法（例如：島到島的虛線＋島內編號、只畫目前這座島的路線、或下一站高亮＋小地圖），並在畫面上說明
   - 嚮導寵物在下一站旁邊，對話泡泡【注音】「下一站：拔蔬菜！」（拔蔬菜在滑鼠島，`units.json` 的 mouse-2），按泡泡＝開那一關的面板
   - 右上角年級膠囊「🎒 1–2 年級 ✏️」
   - 已玩過的站打勾（畫 2–3 個打勾的例子）
4. **清單模式＋年級篩選**：現在的「📋 清單」是一個彈出面板列出全部關卡（見 `home-now.png` 的下方按鈕），加上年級篩選（1–2／3–4／5–6／全部），篩選跟目前年級同步

## 舊介面全部保留（改版不能拿掉）
左上標題、右上的玩過幾關（改成「玩過 2／35 關」）、📥 收成績、👨‍🏫 老師入口（旁邊加「老師」兩個字）、下方「🌏 全景｜📋 清單」切換。
新元素要融進現有風格：現在首頁是奶油色卡片 `#fffaf2`、深咖啡字與粗外框 `#3b2f2a`（3px）、硬陰影 `0 5px 0`、圓角 20px、強調色 `#d9480f`、字型 Noto Sans TC。可以加新色，但不能跟現有地圖插畫打架。

## 底線（三版都要守）
- 文字對比 ≥ 4.5:1；觸控目標 ≥ 44px；1366×657 一屏不捲動
- 單一 HTML 檔，圖只能用 `home-data/` 裡的檔案與 inline SVG；字型只用 Google Fonts＋上面的注音字型；不要用 emoji 當主要圖案（右上角原本就有的 📥、👨‍🏫 這類小圖示可以）
- 不連續閃爍；動畫只在回饋瞬間、prefers-reduced-motion 時關掉
- 介面文字繁體中文（台灣用語）
- 檔名照指定，放在 `docs/plans/mockups/`

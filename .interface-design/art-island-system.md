# 畫畫島設計規範（2026-11-21 選定 A 版「貼紙畫冊」）

來源：`docs/plans/mockups/art-island-frontend-design.html`（5 畫面）；需求 `docs/plans/mockups/art-island-brief.md`；規劃 `docs/plans/2026-11-21-art-island-plan.html`。
適用：畫畫島 6 關（調色魔法鍋 unit24、線條小火車 unit25、魔法畫畫屋 unit18、對稱魔鏡工坊 unit26、小畫家任務局 unit27、像素小畫家 unit5）＋共用外殼 `assets/js/art-ui.js`。Gemini 生成各關時把這份整段附進提示詞。
打字島的規範在 `system.md`，兩座島各用各的，不混。

## 方向
貼紙畫冊：湖水綠點點底的桌面上，貼著一張張粗墨藍輪廓的貼紙卡片和白畫布（畫布上方貼黃色膠帶）。硬陰影（往下位移、不模糊）讓每張卡像厚貼紙。角色是 Q 版、有臉的物件（魔法鍋、森林小熊）。活潑、字大、留白多；**白畫布永遠是畫面主角**，裝飾不能比畫布搶眼。

## 色票（不改名，6 關共用）
| token | 值 | 用途 |
|---|---|---|
| --lagoon | #E4F1F0 | 介面底，配 `radial-gradient(#C3DEDF 1.6px, transparent 1.7px)` 24px 點點 |
| --card | #FFFBEF | 面板、卡片、一般按鈕底 |
| --canvas | #FFFFFF | **只給畫布**（顏色才看得準）；其他地方不用純白大面積 |
| --ink | #1F2A4D | 主要文字＋所有貼紙粗輪廓＋硬陰影；卡片上 13.6:1 |
| --ink-2 | #43507A | 次要文字、標籤；卡片上 7.6:1、底色上 6.8:1 |
| --blue / --blue-soft | #2160C4 / #DCE9FB | **重點／現在／被選到**：目前工具、目前模式、目前關卡、新作品；藍字在淺藍底 4.8:1 |
| --sun / --sun-soft | #FFB627 / #FFF0C2 | **主要按鈕**（開始、完成、倒到圖上、交成績）、星星；按鈕上深藍字 8.0:1 |
| --ok / --ok-dk / --ok-soft | #1B7F45 / #166B3A / #D8F1DF | **正確**＋✓；**淺綠底上的字一律用 --ok-dk**（5.5:1；--ok 只有 4.2:1 不夠） |
| --bad / --bad-soft | #C0303A / #FFDCD8 | **錯誤**＋✗；淺紅底上的字用 #8E1F29（6.9:1） |

- 每個畫面意思色固定 4 個：藍＝現在、黃＝按鈕、綠＝對、紅＝錯。對錯一律同時有 ✓／✗ 或文字
- **顏料色不算介面色**：調色鍋的紅黃藍白黑、色盤 12 色、像素格顏色是畫畫內容，不受上面限制
- 鎖住的關卡：底 #DDE3EA、框 #4B5578、陰影 #7C86A6、字 #3A4568（7.3:1）

## 字體（Google Fonts：`Chiron GoRound TC:wght@700;900`、`Noto Sans TC:wght@400;500;700;900`、`Fredoka:wght@600;700`）
- 標題／關卡名／大按鈕字：Chiron GoRound TC（圓體，支援中文），後備 Noto Sans TC、Microsoft JhengHei
- 介面文字：Noto Sans TC，≥16px，一般 18–20px
- 數字（步數、星數、分數）：Fredoka，後備 Bahnschrift；`font-variant-numeric: tabular-nums`
- **注音**：Bpmf Huninn 子集，只用在 1–2 年級要讀的句子（玩法、角色台詞、煮錯提示）。字型子集由 `tools/subset-bpmf-font.py` 依頁面文字產生；破音字讀音以教育部《重編國語辭典修訂本》為準，預設讀音不對的字要加 IVS（`String.fromCodePoint(0xE01E0 + n - 1)`），**不可用 `<ruby>`**。改了注音句就要重跑子集
- 字級參考（1366×657）：大標 92px、開始鈕 56px、畫面標題 22–27px、按鈕 20–23px、注音句 28–32px

## 形狀與深度
- 輪廓：3px --ink；畫布 3px、圓角 8px；卡片圓角 14–18px；按鈕圓角 14px（開始鈕 24px）
- 硬陰影：`box-shadow: 0 4–8px 0 var(--ink)`（不模糊）；按下 `translateY(3px)` 陰影縮成 1px
- 膠帶：86×26px、#FFD966、略透明、斜貼在畫布或作品卡上緣，一張最多兩條
- 被選到：淺藍底＋藍框＋外圈 2px 藍（`box-shadow: 0 0 0 2px var(--blue)`），右上角藍色 ✓ 小圓
- 圖示：線條 SVG（stroke 2.2、圓角端點），**不用 emoji 當圖示或主圖**（Windows 會變醜）；🏠 只能當文字裝飾，按鈕內一律用 SVG 房子

## 共用版面（1366×657 一屏不捲動）
- 頂列 62px：左「🏠 首頁」（SVG 房子＋字，回 `../../index.html`）、中間任務條／標題（可省）、右「我的畫廊」
- 開始畫面：左側主角插圖、右側大標＋玩法句＋開始鈕、旁邊虛線框「這關練什麼」給老師（課綱代碼照規劃頁）、下方一排關卡卡（120px 縮圖＋第幾關＋名稱＋星星／還沒玩／鎖住）
- 繪圖畫面：左工具面板（筆刷粗細、色盤 4×3、工具）＋中間白畫布（最大）＋右側模式／任務／完成鈕；任務局改成上方一條工具列（像真的繪圖軟體：圖示＋字，分組用直線隔開）＋左目標圖、右我的畫布
- 完成畫面：左作品大圖（膠帶貼）、右「完成了！」＋星星（彈出動畫，reduced-motion 時不動）＋稱讚句＋按鈕兩排、下方畫廊一排縮圖（剛完成的那張藍框＋「新」）
- 觸控：工具、色塊、顏料瓶、按鈕都 ≥ 44px（mockup 是 48–60px）；畫布用 pointer events，滑鼠和觸控同一套

## 互動與護眼
- 不連續閃爍（每秒 ≤ 3 次）；煮錯、畫錯用搖一下＋表情，不用滿版紅閃
- 動畫只用在回饋瞬間（冒泡、星星彈出、火車開過），`prefers-reduced-motion` 時關掉
- 混色：照美術課顏料規則（紅＋黃＝橘、黃＋藍＝綠、紅＋藍＝紫、三色都加＝泥巴色），用查表，不用 RGB 平均

## 方向
黏土點心屋：桃杏奶油底、淡紫頂欄，卡片和按鈕像厚厚的黏土玩具（厚邊＋內亮邊＋底部壓痕＋柔和投影）。主角是孩子領養的寵物，**寵物要大、表情要讀得出來**；題目區保持乾淨，裝飾不能干擾讀題。點心餅乾是貫穿 6 關的成長代幣。

- 每個畫面意思色固定 4 個：橘＝按鈕、紫＝導覽／現在、綠＝對、紅＝錯；對錯一律同時有 ✓／✗ 和文字
- 年段標籤：1–2 年級 #FFE1CB 框 #F2B88E、3–4 年級 #E3D9FB 框 #B7A3EE、1–4 年級 #D6F0E2 框 #9AD3B3，字一律 --ink；**正式版加小圖示區分**（mockup 只靠文字，低年級難分）

## 字體（Google Fonts：`Noto Sans TC:wght@500;700;900`、`Baloo 2:wght@700;800`）
- 介面與標題：Noto Sans TC，≥16px，一般 18–24px，標題 900
- 數字（題號、點心數、答對數）：Baloo 2（`.num`），後備 Noto Sans TC
- **注音**：Bpmf Huninn 子集，只用在 1–2 年級要讀的句子（玩法、題目、寵物台詞、答對答錯、結算）。子集由 `tools/subset-bpmf-font.py` 依頁面文字產生；讀音以教育部《重編國語辭典修訂本》為準，預設讀音不對的字加 IVS（`String.fromCodePoint(0xE01E0 + n - 1)`），**不可用 `<ruby>`**；改了注音句就要重跑子集
- 3–4 年級的關卡題目用一般字型即可

## 形狀與深度
- 黏土卡 `.clay`：3px --edge 框、圓角 26px；`inset 0 3px 0 #fff, inset 0 -6px 0 rgba(233,213,196,.55), 0 8px 0 #EBD6C5, 0 16px 26px rgba(59,35,80,.12)`
- 按鈕 `.btn`：min 48px、圓角 18px、3px 框、900 20px；hover 上浮 2px、按下下沉 2px（.18s ease-out）
- 進度豆：16px 圓點，完成＝紫、現在＝橘放大 1.25、未做＝白底紫框
- 星星：#FFC233 填色、#A8670E 描邊；沒拿到 #F1E6DA
- 焦點：4px --violet outline、offset 3px
- 圖示：線條 SVG，**不用 emoji 當圖示或主圖**；🏠 首頁、💡 提示在按鈕內用 SVG

## 寵物（mockup 的 `pet(type, stage, mood, opts)` 產生器是正式版起點）
- 4 隻原創：雲朵兔（耳尖 Wi-Fi 弧線，寶寶 1 條→大朋友 3 條）、鍵盤龜（斜前方角度、背殼鍵帽、中間一顆橘鍵）、螢幕貓（橘框螢幕頭＋貓耳、表情是深色螢幕上的薄荷線條、大朋友有插頭尾巴）、燈泡雞（頭頂燈泡，開心／驚訝會亮，靜態光暈不閃）
- 3 階段：寶寶（坐在蛋殼裡）→ 小朋友 → 大朋友；表情至少開心、普通、擔心、驚訝、吃東西
- 服裝疊穿：紅條紋圍巾、藍毛線帽、圓框眼鏡（螢幕貓的眼鏡框改黃色）
- 原創性：雲朵兔要跟「白色雲朵＋長垂耳」的既有角色拉開（保持直立耳、Wi-Fi 弧線、團塊雲身）；螢幕貓保持貓耳＋插頭尾巴等自己的特徵

## 共用版面（1366×657 一屏不捲動）
- 頂欄 66px（--lilac 底）：左「首頁」（回 `../../index.html`）、中間島名膠囊＋畫面標題＋年段標籤、右題號進度或「換寵物」
- 遊戲畫面：左／中題目區（1–2 年級題目放大注音）＋寵物在旁陪伴（期待表情）；答對答錯用卡片顯示，**答錯也讓孩子繼續（寬鬆）**，語氣溫和

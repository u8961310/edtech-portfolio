# 打字島設計規範（2026-11-20 選定 C 版「繪本剪紙」）

來源：`docs/plans/mockups/typing-island-interface-design.html`（6 畫面＋第 3 層大鍵盤）；需求 `docs/plans/mockups/typing-island-brief.md`。
適用：打字島 8 關（射擊 5、怪獸對打 3）＋共用核心 `assets/js/typing-core.js` 的設定面板、提示、結算、獎狀、休息卡。Gemini 生成各關時把這份整段附進提示詞。

## 方向
溫暖繪本／紙張剪貼：米色紙桌面、白卡紙卡片（邊緣略不規則、疊層紙影）、Q 版童書角色（小狐狸、蘑菇怪）。可愛但不幼稚，不用暗底、不用螢光。

## 色票（不改名，8 關共用）
| token | 值 | 用途 |
|---|---|---|
| --paper | #F7E8CB | 桌面底（不用純白） |
| --card / --card-2 | #FFF8E6 / #FDF1D8 | 卡片、控制項底 |
| --kraft / --kraft-2 | #E4CC9C / #C9A66B | 牛皮紙邊、hover、鍵帽邊 |
| --ink-1 | #3B2A20 | 主要文字（不用純黑），卡片上 12.9:1 |
| --ink-2 / --ink-3 | #5E4838 / #74604E | 次要 / 標籤（≥4.5:1） |
| --ink-4 | #53402D | 已打完的字（淡綠底上 8.0:1） |
| --sky-dk / --sky-soft | #1F6B9C / #D6EEFB | **現在／重點**：目前字框（11.4:1） |
| --leaf / --leaf-dk | #7CCB6F / #2D7A38 | **正確**＋✓ |
| --berry / --berry-dk | #E5484D / #B3262B | **錯誤**＋✗（底 #FFD9D6） |
| --peach / --peach-dk / --peach-soft | #FF9E7A / #D9531F / #FFDCCB | **按鈕／被選到**、大數字 |
| --butter / --butter-soft | #FFD966 / #FFF1B8 | 只當背景：便利貼、計時牌、獎狀 |

每畫面意思色固定 4 個：天藍＝現在、草綠＝對、紅＝錯、橘＝按鈕。對錯一律同時有 ✓／✗ 或文字。

## 字體
- 介面：Noto Sans TC（後備 Microsoft JhengHei），≥16px，內文 18px
- 數字：Fredoka（後備 Bahnschrift），tabular-nums
- 國字＋注音：Bpmf Huninn 子集 `assets/typing/fonts/bpmf-huninn-typing.woff2`；破音字以 IVS 顯示（讀音依教育部重編國語辭典）；**任何顯示國字的地方（目標物、詩句、錯字、鍵帽）都要套 IVS，不可寫死字元**
- 打字區字級：初階 56px、進階 50px、高階 46px（含注音），最低 40px

## 形狀與深度
- 圓角略不規則（6／10／16px 混用）、紙片疊層陰影 `--sh`；按壓用 translateY 下沉
- 鍵帽：白底＋牛皮紙底邊

## 版面（1366×657 一屏不捲動）
- 上：HUD 卡（回合路標點、剩餘時間便利貼、愛心血量、連擊、正確率）
- 中：遊戲場景（森林／草地，草地線＝扣血線）
- 下：詩句卡（目前字天藍框；打對淺綠底；打錯紅框＋✗ 徽章）＋提示階梯一整排（①紅閃 ②鍵帽 ③「暫停，看大鍵盤」）
- 第 3 層：遊戲暫停，大鍵盤面板蓋下半部，半透明米色遮罩；每格 ≥44px（實作 62×50）、英文 16px、注音 18px；完整 5 排 59 鍵、實體寬度與錯位、F J 凸點、大千對照由單一資料表產生；「我知道了，繼續打字」或 Esc 關閉

## 動態與護眼
- 紅閃 0.5 秒一次、共 2 次就停（≤3 次/秒）；無滿版閃光；`prefers-reduced-motion` 全關
- 回合間「休息一下」畫面：看遠方 20 秒、眨眼、動一動，20 秒倒數可略過

## 獎狀
黃色緞帶標題「獎狀」、學生名字（第一次闖關問、存 localStorage）＋「小朋友」、內容句（文章類別・階級、正確率、每分鐘字數）、★ 稱號（打字小學徒／小高手／小達人）、民國日期、打字島印章；右側名字欄與稱號表；`@media print` 只印獎狀本體

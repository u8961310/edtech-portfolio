# 滑鼠島設計規範（2026-11-22 選定 C 版「海島尋寶地圖」）

來源：`docs/plans/mockups/mouse-island-interface-design.html`（5 畫面）；需求 `docs/plans/mockups/mouse-island-brief.md`；規劃 `docs/plans/2026-11-22-mouse-island-plan.html`。
適用：滑鼠島 7 關（滑鼠勇士 unit21、敲敲蛋寶寶、拔蔬菜 unit19、小兔勇者 unit2、右鍵魔法師、海底捲捲探險、牧場圍圍樂）＋島大廳＋共用外殼 `mouse-ui.js`。Gemini 生成各關時把這份整段附進提示詞。
打字島 `system.md`、畫畫島 `art-island-system.md`、小常識島 `smart-island-system.md` 各用各的，不混。

## 方向
海島尋寶地圖：明亮沙灘、海藍、珊瑚橘、棕櫚綠、木頭與繩子。大廳是一張手繪尋寶地圖，虛線小路就是**技能階梯**，過橋之後是 3–4 年級的關，終點是寶箱。每練會一個技能，寶箱蓋亮一顆寶石。吉祥物是戴船長帽的小寄居蟹「寄寄」。
**練滑鼠的目標一定最突出**：場景（沙灘、木地板）保持安靜，目標用金色光暈＋深色外圈，好玩的反應放在操作結果上，不放在目標旁邊。

## 色票（不改名，7 關共用）
| token | 值 | 用途 | 對比 |
|---|---|---|---|
| --sand | #F6E7BE | 地圖、遊戲場景底 | ink 11.9:1 |
| --parch | #FFF8E4 | 卡片、對話框、按鈕底 | ink 13.8:1、ink-2 6.2:1 |
| --sea | #BFE1EA | 頂欄、海面 | ink 10.6:1 |
| --sea-d | #236F96 | **導覽／資訊**：回滑鼠島、3–4 年級旗子 | 白字 5.6:1 |
| --coral / --coral-l | #C2432A / #E8704F | **重點／現在**：目前這一段、下一站、交成績、1–2 年級旗子 | 白字 5.1:1 |
| --palm | #2F7A49 | **完成／成功**＋✓、1–4 年級旗子、再玩一次 | 白字 5.3:1 |
| --gold | #F2B134 | 星星、寶石、**目標發光** | ink 7.8:1 |
| --ink / --ink-2 | #33261B / #6B5A48 | 主要／次要文字（不用純黑） | 見上 |
| --wood / --wood-d / --rope | #9A5F36 / #6E4125 / #B9794A | 寶箱、木牌、卡片外框 | 裝飾 |
- 意思色固定：珊瑚＝現在／重點、棕櫚綠＝完成／成功、海藍＝導覽、金＝目標與獎勵。失手不用紅色「錯」，用搞笑反應＋文字
- 年段旗子：1–2 年級珊瑚、1–4 年級棕櫚綠、3–4 年級海藍；旗子上有文字，不只靠顏色
- **目標發光**：金色光暈對沙色底只有 1.5:1，**一定要搭配深色外圈**（--ink-2 虛線環或 --wood-d 描邊），不能只靠光暈
- 次要文字放在 pill 底（#E9D9B0）上只有 4.7:1，pill 上的字改用 --ink

## 字體（Google Fonts：`Noto Sans TC:wght@400;500;700;900`）
- 介面：Noto Sans TC，≥16px，標題 900
- **注音**：Bpmf Huninn 子集（`.zy`，字寬約 1.35em，`white-space:nowrap`），**1–2 年級看得到的字全加**：大廳關卡名、技能名、年段旗子、寄寄的對話、段落名稱、提示句、按鈕、圖鑑、結算文字。只有老師小區塊和 3–4 年級關（右鍵魔法師、海底捲捲探險、牧場圍圍樂）的題目用一般字型
- 讀音以教育部《重編國語辭典修訂本》為準。字型預設不對的加 IVS：係（沒關係）→ U+E01E1 輕聲。字型畫不出的就換字：「拖曳」給小朋友看的地方寫「拖拉」、「自己試試」改「自己來」。**不可用 `<ruby>`**；改了注音句就重跑 `tools/subset-bpmf-font.py`
- 句子避開常讀錯的字：著、得、地、的（非句尾）、長、樂（非 ㄌㄜˋ）、重、行、還、背、教、數、只、為、什麼、怎麼

## 版面（舞台 1366×657，等比縮放，每個畫面不捲動）

- 按鈕 `.btn`：60px 高、圓角 16px、700 20px、底部 4px 硬陰影；coral／palm／sea 三色＋line（parch 底 rope 框）

## 鷹架怎麼畫（7 關共用，外殼負責）
- 第一段「看我示範」：畫面最乾淨，目標大、不動；手指示範＝白色大游標在目標上點擊，配 ① ② 圓章（點兩下時）；寄寄說「看我按一次」
- 第二段「自己來」：目標中等慢動；頂欄右側一句「失手沒關係，慢慢來！」
- 第三段「小挑戰」：目標小、會動或有干擾物
- 提示 1（失手 2 次）：目標金色光暈＋深色外圈＋一句方向提示（.zy），目標本身做搞笑反應（蛋笑、左右晃＋「嘻嘻嘻～」）
- 提示 2（失手 4 次）：重播手指示範，寄寄說「看我再按一次」
- 提示 3：自動放慢、目標放大（不另外跳卡）
- 不畫愛心／生命值；星星只反映失手次數

## 收集與獎勵
- 寶箱蓋 7 個寶石槽：沒亮＝深木色虛線圓、亮了＝金或彩色寶石
- 寶石落槽動畫：寶石從上方落進空槽，落定時光環擴散＋6 顆小星星噴出，約 0.85 秒、只播一次；`prefers-reduced-motion` 直接顯示亮起
- 蛋寶寶圖鑑：12 格（已收集＝小動物 SVG、沒收集＝虛線「?」格、最後一格彩虹蛋），新解鎖卡左上珊瑚色「新解鎖」標
- 集滿 7 顆寶石 → 滑鼠小達人證書（印名字）

## 角色與圖案
- 寄寄（寄居蟹）：珊瑚紅身體、螺旋殼、深藍船長帽、大眼睛；每個畫面角落出現，示範／鼓勵／慶祝
- 地標（大廳）：貓咪燈塔、蛋蛋山、蔬菜田、小兔城堡、魔法塔、海底入口、羊咩咩牧場，終點寶箱 X
- 全部 inline SVG，簡單幾何組合；**不用 emoji 當主要圖案**（🏠 首頁按鈕內可以）
- 動畫不連續閃爍（每秒 ≤ 3 次）；所有動畫都有 reduced-motion 版本
